# 微信公众号推文图文归档

[English](README.md) | [简体中文](README.zh-CN.md)

> 抓取公众号推文的完整正文和防盗链图片，归档到本地。

## 这是什么

这不是一个收藏夹工具，也不是"打印成 PDF"的配方。这两种都会把图片丢掉：公众号的图片走的是校验 referer 的 CDN，直接抓只会拿到正文加一堆裂图。

这个技能就是把这条链路走通：正文用一种方式取，图片真实地址用另一种方式提，然后每张图带着正确的 referer 下载。

## 为什么开源

我们归档文章是常态 —— 竞品拆解、行业分析、任何会影响判断的材料。存个链接是不够的，链接会烂，文章会被改、会被删。

公司里日常就是拿它做这类调研归档。它不含任何专有方法，分享出来没有任何负担。

## 能做什么

- **正文完整提取。** 标题、发布账号、发布时间、正文全文、小标题、其中的数据，一次取全。
- **图片真实地址。** 用浏览器那一步拿到 HTML 里根本没暴露的真实图片地址。
- **referer 正确下载。** 每张图带着微信 CDN 要求的 referer 去取，这才是能下下来的关键。
- **逐张读图。** 图片会一张张开出来看，避免"其实没下下来"被当成成功。
- **本地归档产物。** 文字和图片落到一个可检索、可备份、能留存的目录结构里。

## 安装

```bash
git clone https://github.com/<你的用户名>/wechat-article-archive.git
```

然后把整个目录放进技能目录：

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<你>\.workbuddy\skills\wechat-article-archive\` |
| macOS / Linux | `~/.workbuddy/skills/wechat-article-archive/` |

没有构建步骤，重启对话即生效。

## 怎么用

丢一个链接进来说要做什么就行：

- "读一下这篇推文，告诉我有什么有用的"
- "把这篇文章连图片一起归档"
- "把这篇存进知识库"

它会取正文、恢复图片地址、带正确 referer 下载，你如果要总结就接着总结。

## 注意与边界

1. **图片链接实际会失效。** 想留住图片，只有当场归档这一条路；过一阵再去抓旧地址，经常会失败。
2. **要图就必须走浏览器那一步。** 想拿图片的话，没有纯文本的捷径绕过去。
3. **文章结构各不相同。** 有些号排版很重。提取覆盖常见情况，覆盖不到的地方会写明。
4. **尊重来源。** 归档内容保留原始署名，这个工具不会抹掉出处。
